# Données

Le fichier de données n'est pas dans le dépôt : je ne suis pas autorisé à le rediffuser.

C'est un extrait du recensement de la population 2015 de l'Insee pour l'Île-de-France. Il compte une ligne par couple dont les deux conjoints travaillent, soit 282 271 couples. Pour chaque conjoint, il contient les variables du recensement (âge, profession, diplôme, mode de transport, commune de travail) et des variables de trajet calculées en amont : distance domicile-travail, temps en voiture, temps en transports en commun.

Les scripts attendent ce fichier ici, sous le nom `couple_biactives_2015.parquet`.
